## Two rules that apply to every track

1. **Build it by voice.** Dictate prompts, specs and fixes into an AI builder (Lovable, Bolt, Cursor, Replit, Claude) using Wispr Flow.
2. **Make it work with voice.** Natural speech through Wispr Flow is the main input. The agent must turn filler words, digressions and self-corrections into structured output.

## Our track: Track 3, Meeting-to-execution agent

Must-build list from the problem statement:

1. Transcript ingestion with speaker attribution
2. Extraction of decisions, action items, owners and deadlines
3. Detection of conflicts with earlier decisions stored in memory
4. Task creation in a tracker through an integration
5. Reminders before deadlines
6. Weekly digest per person
7. Confirmation step before anything is posted

The page says cross-meeting memory and conflict detection are what make it "a real system rather than a transcript summarizer."
